# Ridgeline Roofing Services

Single-file front-end rebuild for Ridgeline Roofing Services, designed from the supplied premium landing-page reference while retaining Ridgeline's real brand colours, logo, business content and original roofing/portfolio images.

## Files

- `index.html` — self-contained responsive website
- `RIDGELINE_BUILD_BRIEF.md` — design/content requirements and source asset list

## Preview

Open `index.html` directly or serve the repository with any static web server.

## Important before production

The quote form is currently a front-end prototype: it validates and shows a success state but does not transmit or store customer data. Connect it to the chosen backend / CRM / email workflow before launch.
